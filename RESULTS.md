## Reading these numbers honestly

**Two configurations, two different questions.** The production configuration answers *how well does the system work*. The controlled comparison handicaps every pipeline onto the same LLM compiler and answers *does adaptivity help* — absolute accuracy is low there for all three because an 8B model is a poor NL→query compiler, which is the variable under test.

**Cost per correct answer, not cost per question.** A pipeline that is cheap because it declines to answer is not efficient. On the chained set the agent is both the most accurate and the cheapest per correct answer.

**Negative results are included.** `chained_venue` is 0.00 for all three pipelines. `chained_chronology` is the one family where RAG beats the agent. Neither is omitted.
